# AI education resources

This collection brings together free, open classroom resources for teaching AI literacy and online safety to teenagers aged 12 to 16. It is designed for teachers, school staff, and parents who want practical, ready-to-use sessions that are easy to run without specialist technical knowledge.

Everything in this collection is free to use, adapt, and share. You can use it in class, in workshops, or at home, and you can adjust it to suit your learners.

## How to use

Open the link in any browser. There is no install step and no account needed.

Use the arrow keys to move between slides, press X to open the team scoreboard, and press Space for the 3-2-1 vote countdown. This works best on a projector or a large screen so the whole group can see it clearly.

## Adapting the materials

You can download the HTML file and edit it to fit your setting. If you want to shorten a section, add local examples, or tailor the activity to your learners, you can make those changes before using it.
